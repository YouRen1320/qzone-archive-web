# Contributing

Thank you for helping improve this project.

1. Open an issue for architecture, API, storage, or privacy changes before implementation.
2. Never include real QQ cookies, QR codes, QQ numbers, nicknames, feed content, or production task directories in tests and reports.
3. Use a short-lived branch and Conventional Commit messages.
4. Run `npm test && npm run build` in `frontend/`.
5. Run `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings`, and `cargo test --all-targets` in `backend/`.
6. Explain behavior, privacy impact, migration impact, verification, and rollback in the pull request.

By contributing, you agree that your contribution is licensed under GPL-3.0-only.
