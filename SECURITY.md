# Security policy

Please do not open a public issue for vulnerabilities that could expose QQ credentials, task-owner secrets, archive contents, server paths, or cross-user data.

Use GitHub's private vulnerability reporting for this repository. Include a minimal reproduction without real QQ cookies, QR codes, or personal archive data. Maintainers will acknowledge a valid report as soon as practical and coordinate a fix before disclosure.

Supported security updates target the latest release only.
