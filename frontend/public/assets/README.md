# Visual asset provenance

`jiangnan-borrowed-view.webp` and its mobile derivative were generated specifically for this project with OpenAI's built-in image generation tool, then compressed locally. They are original project assets and are distributed under the repository license.

The brief requested a restrained Jiangnan borrowed-view scene: warm rice paper, a quiet moon-gate arc, white walls and dark tiles, a distant bridge, muted jade ink, generous negative space, and no people, text, logos, QR codes, or copied reference imagery.

The interface keeps all functional copy, status, and controls in accessible HTML; these files are decorative only.
